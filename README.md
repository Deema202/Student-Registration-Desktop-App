# Student Registration Desktop App 🎓

A simple and clean Desktop Application built with Python, featuring a Graphical User Interface (GUI) using **Tkinter**, data persistence using **SQLite3**, and data visualization using **Matplotlib**.

## Features ✨
* **Student Registration Form:** Add student details (Full Name, Email, and Gender).
* **Database Integration:** Automatically creates an SQLite database and stores student records securely.
* **Data Visualization:** Interactive Pie Chart showing the gender distribution of registered students using Matplotlib.
* **Object-Oriented Programming (OOP):** Well-structured codebase separated into modular classes.

## Technologies Used 🛠️
* **Python**
* **Tkinter** (GUI Framework)
* **SQLite3** (Database)
* **Matplotlib** (Data Visualization)
